# 先分清：官方套餐 vs 第三方代充

整理日期：2026-11-03（Asia/Shanghai）。

## 两条路径

| | 官方直接订阅 | 第三方代充（如 PayForGPT） |
| --- | --- | --- |
| 付钱给谁 | OpenAI / Apple 等官方通道 | 独立第三方商店 |
| 常见障碍 | 需要可用外卡；部分地区支付失败 | 用支付宝 / 微信 / USDT 等本地方式（以结账页为准） |
| 账号归属 | 你的 ChatGPT 账号 | 仍是你的账号；商家不接管密码 |
| 售后 | 官方账单与帮助中心 | **原下单站**查单与售后；不要跨站混用订单号 |
| 隶属关系 | 官方 | **与 OpenAI 无隶属关系** |

## 三种费用不要混

1. **ChatGPT 订阅**（Free / Plus / Pro）：决定网页与 App 里多数模型额度。
2. **Codex 等产品用量**：可能与订阅共享或另计，以账号内提示为准。
3. **API / Platform 账单与 Credits**：走 platform.openai.com，**不等于** Plus 月卡。本仓库与 PayForGPT **不售卖**官方 Credits；见 [05](05-official-credits-info-only.md)。

## 什么时候适合考虑第三方

- 官方支付反复失败，或没有可用外卡。
- 需要人民币结账、订单号可查、中文售后。
- 你能接受：交付方式以商品页为准（例如兑换码），且你愿意按商家规则保留查单密码。

## 什么时候不要硬买

- 你其实只需要偶尔提问，Free 已经够用。
- 有人要求你交出密码 / 验证码「代登」。
- 页面承诺无法核实的「固定瞬间到账」「保证永不降智」等话术——当作营销，不要当合同。
