# 下单前安全核对清单

配套阅读：[GPT / ChatGPT 国内充值步骤](https://payforgpt.com/how-to/recharge-chatgpt-plus)、[微信支付通道](https://payforgpt.com/ai-subscriptions/chatgpt-wechat-alipay-payment)。

## 核对 1：账号

- [ ] 登录邮箱、登录方式（密码 / Google / Apple）已确认。
- [ ] 现有套餐与到期时间已从账号页抄下。
- [ ] **不会**把密码、验证码发给商家。

## 核对 2：商品

- [ ] 选的是 Plus / 5x / 20x 之一，周期与价格与结账页一致。
- [ ] 页面读失败 ≠ 缺货；刷新或换网络后再看。
- [ ] 读完交付方式与质保说明（以商品页原文为准）。

## 核对 3：支付

- [ ] 结账页实际出现的通道（支付宝 / 微信 / USDT / 人工转账等）再付。
- [ ] 保存支付凭证；同一笔款不要重复点支付。
- [ ] 对公/开票需求提前问清，不要根据博客推断票种。

## 核对 4：查单

- [ ] 记下**订单号**与**查单密码**（只存在你自己的密码管理器）。
- [ ] 查单入口：<https://payforgpt.com/order>
- [ ] 不要把查单密码贴到 GitHub Issue、群聊截图或公开评论。

## 核对 5：红线

- [ ] 对方没有索取 Session / Cookie / 二次验证码。
- [ ] 没有要求你安装未知证书或关闭 TLS 校验。
- [ ] 没有用「和某某站同一运营、同价」之类话术逼单——独立站点各自维护商品与售后。

全部勾完再付款。付款后若异常，见 [交付排查](04-payment-not-delivered.md)。
