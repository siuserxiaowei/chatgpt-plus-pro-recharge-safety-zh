# 支付成功但未到账：四段拆开查

不要用「再买一次」当排查手段。按顺序区分：

1. **创建订单**：是否生成了订单号？
2. **付款确认**：支付渠道是否扣款成功？
3. **交付**：兑换码 / 开通动作是否已发出？
4. **激活**：账号页是否已显示对应套餐？

## 建议顺序

1. 打开 [订单查询](https://payforgpt.com/order)，用订单号 + 查单密码看状态与备注。
2. 对照支付 App 里的扣款记录时间与金额。
3. 若订单显示已交付，到 ChatGPT 账号页核对套餐；必要时退出重登（**不要**清掉所有设备会话除非你明白后果）。
4. 仍不一致：通过原站客服渠道提供订单号（不要发密码原文到公开处）。

## 明确不要做的事

- 同一问题连续开多笔单「试运气」。
- 把卡密 / 查单密码发到陌生人私聊。
- 假设「官方客服」会在第三方聊天软件主动要你验证码。
