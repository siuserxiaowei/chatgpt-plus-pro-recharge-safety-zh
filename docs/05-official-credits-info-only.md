# 官方 Credits：仅信息说明（本站不售卖）

**PayForGPT 本仓库与商店不销售 OpenAI API Credits / Platform 余额。** 若你在别处看到「代充 Credits」，请自行核实对方资质与账单归属；本文只做概念分流。

## 订阅 ≠ Credits

| | ChatGPT 订阅（Plus / Pro） | API / Platform Credits |
| --- | --- | --- |
| 用途 | ChatGPT 产品内额度 | API 调用、部分开发者产品 |
| 账单入口 | ChatGPT 账号订阅设置 | platform.openai.com 等开发者账单 |
| 互相顶替？ | **一般不能**把订阅当成 API 余额 | **一般不能**把 Credits 当成 Plus |

官方说明入口示例（页面会更新）：

- [ChatGPT vs API billing](https://help.openai.com/en/articles/9039756-billing-settings-in-chatgpt-vs-platform)

## 如果你真正需要的是 API

1. 确认组织与付款方式在官方 Platform 内完成。
2. 不要把 API Key 贴进第三方「代充」表单。
3. 用量与限额以官方仪表盘为准。
