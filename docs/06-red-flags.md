# 常见误区与红线

## 立刻离开的信号

- 索取 **ChatGPT 密码、短信/邮箱验证码、Session、Cookie、API Key**。
- 要求安装不明根证书、关闭证书校验、或共享屏幕代操作支付。
- 用无法核实的指标逼单（「保证永不封」「固定瞬间到账」等）。本仓库**不编造**任何转化率或到账秒数。
- 把两家无关商店说成「同一运营 / 姐妹店同价」来诱导跳转——对外应按独立站点处理各自订单。

## 常见误解

| 误解 | 更稳妥的理解 |
| --- | --- |
| 付完款就一定立刻显示 Pro | 交付与激活是两步；以订单状态 + 账号页为准 |
| 买了 Plus 就等于有 API 额度 | 见 [Credits 说明](05-official-credits-info-only.md) |
| 商品页打不开 = 缺货 | 先排除网络与缓存 |
| 公开群里的「内部渠道」更便宜更稳 | 渠道越不透明，凭证越难追 |

## 建议保留的证据

订单号、支付时间金额、商品名称、交付回执（卡密只存本地密码库）、账号套餐截图（打码敏感信息）。
